1. ChatGPT / Codex（OpenAI）
Codex が全職種向けに拡張（Sites・役割別プラグイン）
★★ 要注目

2026年6月2日、OpenAI は Codex に6種の役割別プラグイン（データ分析・営業・投資・クリエイティブ等）と、チームで共有できるインタラクティブな Web ページを生成する「Sites」機能を追加。週間アクティブユーザーが500万人を突破し、非開発者（マーケター・アナリスト等）が全体の20%を占めるまで拡大。Sites は Business・Enterprise プラン（$25/人/月〜）のプレビュー提供。

実務影響：Codex が「コーディング専用ツール」から「業務全般の自動化ツール」に変質しつつある。契約先での提案・活用範囲が広がる一方、非エンジニア職との差別化が薄まるリスクも認識しておくべき。

Codex Windows版 Computer Use リリース（5月29日）
新機能

Windows アプリケーションを Codex が直接操作（クリック・入力・確認）できる Computer Use 機能が Windows 版 Codex に追加。Mac で開始した作業を iPhone の ChatGPT アプリからリモート継続することも可能に。Codex Profiles（使用統計・トークンアクティビティの可視化）も対象ユーザーに提供開始。

実務影響：iPhone から Codex の進行中タスクを確認・継続できる点は、外出中の作業管理に直結。ただし現時点では Mac ホストが起動・オンライン状態である必要がある。

GPT-5.5 Instant が全ユーザーのデフォルトモデルに（5月5日）
★ 注視

GPT-5.3 Instant を置き換える形で GPT-5.5 Instant が全プランのデフォルトに。正確性・簡潔さ・画像理解が向上。過去チャットや接続済み Gmail のコンテキストをより効果的に活用するようになった。5月28日のアップデートでは応答スタイルと品質がさらに改善。

実務影響：日常的な ChatGPT 利用の品質が底上げされる。特に繰り返し説明が不要になる点は業務効率に直結する。

o3（8月26日）・GPT-4.5（6月27日）廃止スケジュール確定
★★ 要注目

ChatGPT 上での o3 廃止は2026年8月26日、GPT-4.5 廃止は2026年6月27日に確定。いずれも ChatGPT のみの変更で API は継続。有料ユーザーはモデル設定から廃止まで選択可能。

実務影響：API 経由で o3 や GPT-4.5 を使用するスクリプト・ツールがあれば影響なし。ChatGPT UI 上でこれらのモデルを指定している場合は移行先モデルを確認しておく。
▲ 目次へ戻る
ChatGPT メモリ機能の大幅強化（6月4日）
新機能

過去チャット・保存済みメモリ・ファイル・Gmail から関連コンテキストを自動引き出す「Dreaming」ベースの新メモリシステムを導入。応答の下の「Sources」アイコンでどの情報が使われたか確認・編集可能に。Plus・Pro ユーザーは接続済み Gmail アカウントからのメールも参照対象。

実務影響：iPhone の ChatGPT アプリで同じ背景説明を繰り返す手間が減る。ただし意図しない過去情報が参照される可能性があるため、重要な判断には「Sources」確認を習慣化すべき。

2. GitHub Copilot
AI Credits 課金モデルへ移行（6月1日実施済み）
★★★ 要対応

2026年6月1日より、Copilot の課金体系がリクエスト数カウントからトークン使用量ベースの「AI Credits」に変更。1 AI Credit = $0.01 USD。各プランに月次クレジット枠が設定され、Business・Enterprise は組織全体でプール。

コミュニティでは「数プロンプトで大量消費」「予測不能なコストになった」という報告が相次いでいる。

実務影響（契約先での利用）：契約先が Copilot Business / Enterprise を導入している場合、エージェントモードや大規模リポジトリ解析を多用するとクレジットを急速消費する。チームへの周知と使用方針の策定が急務。インライン補完中心の利用であれば実質的な影響は限定的。

インライン補完・次の編集候補は無制限継続
★ 注視

有料プランにおいて、IDE 上のインライン補完と次の編集候補（Next Edit Suggestions）は AI Credits 消費の対象外として継続。Copilot を「補完ツール」として使う限り、日常的な開発フローへの影響は最小限。

実務影響：VSCode でのコード補完中心の利用であれば、今回の課金変更による直接的なコスト増はない。ただし今後 Agent 機能の利用拡大を検討する際は、クレジット消費量を事前に把握する必要がある。

★ 注視

Microsoft Build（2026年5月）で、Microsoft 独自開発のコード生成特化モデル MAI-Code-1-Flash が GitHub Copilot および VSCode に統合されることが発表された。OpenAI への依存度を下げつつコスト効率を高める狙いがある。

Agent SDK 課金分離（6月15日実施予定）

2026年6月15日より、Claude Agent SDK・ヘッドレス Claude Code（claude -p）・Claude Code GitHub Actions・サードパーティエージェントが、サブスクリプション枠から分離され、API レートで課金される別枠クレジットに移行。

6. 全体俯瞰：今週のキーメッセージ
「定額サブスクリプション」モデルの終焉が始まった

GitHub Copilot（6月1日）と Anthropic Claude（6月15日）がほぼ同時期に従量課金へ移行したことは、AIツールの「食べ放題」時代の終わりを示す構造的変化である。Agent が人間の何十倍ものトークンを消費できるようになった結果、定額モデルが維持不能になった。

フリーランスエンジニアとして複数ツールを使い分けている場合、各ツールの月次コストが予測困難になるリスクがある。使用パターンの可視化と予算上限の設定が今後の必須管理項目となる。

今週の最優先確認事項：
1. 契約先での GitHub Copilot の Agent 機能利用状況を確認し、クレジット消費量を把握する
2. Claude Code を CI/CD や GitHub Actions で自動実行していないか確認する（6月15日まで）
3. Gemini API を直接利用するスクリプトがある場合は移行先モデルを確認する
